# 发票重复检测工具

检查新发票是否与已报销发票重复，防止重复报销。

## 使用方法

1. 左侧「添加 PDF」导入已有报销记录 → 自动提取发票号入库存

2. 右侧「选择 PDF 文件」导入待审核发票 → 自动提取发票号

3. 点击「开始比对」→ 左右两侧同时高亮重复项

4. 左侧可单选删除或一键清空全部记录

## 运行

```bash
pip install pdfplumber
python app.py
```

或下载 `dist/` 中的 `.exe` 直接运行。

## 数据存储

已报销库保存在 `~/.invoice_duplicate_db.json`，关闭程序后记录不丢失。
